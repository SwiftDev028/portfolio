# MEDICORE CLINIC — Private Healthcare Website

A premium private clinic website concept featuring doctor booking, doctors catalog, medical services, lab tests, multi-step appointment flow and responsive healthcare UX.

## Technologies

- HTML
- CSS
- JavaScript
- Responsive Design
- UI/UX Design
- Healthcare Website
- Appointment Booking
- Filters
- Lab Tests Cart

This project was created as a portfolio case for [almirkhialov.ru](https://almirkhialov.ru). It is a static concept and does not provide medical advice, real appointments or payments.
