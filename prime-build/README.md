# PRIME BUILD — Premium Renovation Company Website

A premium renovation company website concept focused on apartment renovation, interior design, cost calculation and lead generation. The project includes service pages, project portfolio, renovation calculator, contact forms and responsive premium UI.

## Technologies

HTML, CSS, JavaScript, Responsive Design, UI/UX, Calculator, Lead Generation Website.

## Pages

- Home
- Services
- Projects
- Project detail
- Calculator
- About
- Contact

Open `index.html` directly or serve the folder with any static server.
