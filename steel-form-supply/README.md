# STEELFORM SUPPLY — Industrial B2B Website

Современная концепция B2B-сайта поставщика металлопроката и строительных материалов в России. Проект включает каталог продукции, корзину заявки, страницу логистики, портфолио поставок, калькулятор и корпоративный UX для лидогенерации.

## Страницы

- Главная
- Каталог
- Карточка товара
- Услуги
- Логистика
- Проекты
- О компании
- Контакты

## Технологии

- HTML
