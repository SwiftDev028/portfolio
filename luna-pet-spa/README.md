# LUNA PET SPA — Luxury Grooming Website

Премиальный многостраничный сайт груминг-салона для портфолио almirkhialov.ru.

## Что внутри

- Главная страница с hero, статистикой, услугами, puppy experience, wellness и before/after.
- Страница услуг с 8 премиальными карточками.
- Страница цен с пакетами и FAQ.
- Галерея с фильтрами и masonry-сеткой.
- Pet Journal с карточками статей.
- Страница о салоне с философией, командой, стандартами и FAQ.
- Контакты с формой и toast-уведомлением.
- Онлайн-запись с пошаговым сценарием.
