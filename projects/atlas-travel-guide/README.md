# Atlas Travel Guide

Премиальный концепт travel-платформы для портфолио Almir Khialov.

- Горизонтальная лента направлений
- Editorial travel stories
- Фильтруемые места и добавление в маршрут
- Готовые маршруты и animated timeline
- Demo AI trip suggestion
- Стилизованная карта без внешнего API
- Нативные анимации с поддержкой reduced motion
